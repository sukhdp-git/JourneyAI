# journzey Instagram post style ("Edge Notes" theme)

This is the required look for every Instagram post. Reference post: `journzey-edge-notes-01-v2-page1.png` / `-page2.png`.
Template: `edge-notes-01-v2-light.html` (copy it for each new post; render at 1080×1350).

## Format
- 1080×1350 px (4:5 portrait), usually a 2-page carousel: page 1 = hook, page 2 = useful method + the app + call to action.
- Series tag top right: `EDGE NOTES · NN` (number each post). `journzey` wordmark in the brand gradient top left.
- Page dots bottom right; page 1 bottom left: "How to … →" (swipe prompt); page 2 bottom: "Save this for your next review 🔖".

## Theme (Clean Light, matches the website)
- Background `#f6f5fc` with a soft violet glow (top) and pink glow (bottom right). Cards white, border `#e5e1f5`, soft violet shadow, radius 20–26 px.
- Text: headings `#15132a`, body `#2c2a40`, muted `#636080`, faint `#8f8ca8`.
- Brand gradient `#6541e9 → #8a5ddc → #b17ace → #d996c1 → #feb2b4` (wordmark, highlighted words, number badges, call-to-action bar).
- Profit/loss colours: up `#059669`, down `#dc2626`.
- Fonts: Plus Jakarta Sans (headings bold, tight letter-spacing), Instrument Serif italic for the highlighted second line of the headline (in the gradient), JetBrains Mono for prices, times, tags and numbers.

## Must look like trading
- Every post shows a recognisable trading visual: candlestick chart with price axis, time axis and instrument/timeframe label (e.g. `XAUUSD 15m`), a P&L table, a trade log, risk/R numbers, or a real journzey screenshot.
- Highlight the key point on the visual in red (or green) with a pill label, e.g. "YOUR DANGER HOUR".

## Content rules
- Page 2 gives a genuinely useful method a trader can apply without the app, then shows journzey doing it.
- Label honestly: illustrative charts "Illustration", made-up tables "example", demo screenshots "sample data". Never invent statistics, results or testimonials.
- Pre-launch: call-to-action bar reads "journzey is coming soon · Follow for launch day 🔔". Do not say "free" or "link in bio" until the site is live and the user says so.
- Do not mention CSV import (not working on the live site yet) unless the user says it is fixed.
- Supply a ready-to-paste caption with each post (hook line, value, coming-soon line, question for comments, 5–8 hashtags).
