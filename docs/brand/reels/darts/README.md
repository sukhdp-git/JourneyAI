# Darts reel: "Same first miss. Only one wrote it down." (16 s, 1080×1920)

Format inspired by a viral split-screen stick-figure comparison reel; original story, visuals and sound.
- `darts.html`: the animation (canvas, `draw(t)`), journzey dark theme, violet/pink dartboard.
- `sfx.py`: generates the sound design (pad, whooshes, hits, loss/win sounds, scribbles, typewriter).
- `journzey-darts-reel.mp4`: final video.
Top "NO JOURNAL" misses the same spot 5× (−$500). Bottom "JOURNALS EVERY TRADE" writes a note after each miss
(too high ↓ / still left → / closer. same plan.), adjusts and ends +$500. Illustrative numbers.
